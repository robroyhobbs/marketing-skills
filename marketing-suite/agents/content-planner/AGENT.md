# Content Planner Agent

A specialized agent for creating content calendars, planning content strategy, and coordinating multi-channel content production.

## When to Use This Agent

Use the content-planner agent when:

- Planning monthly/quarterly content calendars
- Coordinating content across multiple channels
- Mapping content to funnel stages
- Balancing different content types
- Planning seasonal/campaign content
- Repurposing existing content systematically
- Aligning content with business goals

## Agent Capabilities

This agent can:

1. **Calendar Creation**
   - Monthly content calendars
   - Multi-channel coordination
   - Content type balancing
   - Publish date scheduling

2. **Strategic Planning**
   - Map content to funnel stages
   - Balance evergreen vs. timely
   - Plan content clusters
   - Coordinate campaigns

3. **Content Mapping**
   - Keywords → content ideas
   - Topics → formats
   - Campaigns → content needs
   - Repurposing opportunities

4. **Resource Planning**
   - Production timeline
   - Asset requirements
   - Team coordination
   - Efficiency optimization

## How It Works

The agent will:

1. **Gather Context**
   - Business goals
   - Available keywords/topics
   - Content resources (team, budget)
   - Existing content assets
   - Channel priorities

2. **Design Strategy**
   - Content themes for period
   - Channel mix
   - Content types
   - Publishing frequency

3. **Build Calendar**
   - Specific content ideas
   - Publish dates
   - Format/channel assignments
   - Production timeline

4. **Create Production Plan**
   - Batching opportunities

   - Asset requirements
   - Team assignments

## Content Balancing

The agent ensures balance:

### Topic Balance
```
✅ Good:
- Pillar 1: 40%
- Pillar 2: 30%
- Pillar 3: 30%

❌ Bad:
- Pillar 1: 90%
- Pillar 2: 10%
- Pillar 3: 0%
(Too narrow, audiences get bored)
```

### Funnel Balance
```
✅ Good:
- TOFU: 50% (attract)
- MOFU: 30% (nurture)
- BOFU: 20% (convert)

❌ Bad:
- TOFU: 10%
- MOFU: 10%
- BOFU: 80%
(Too salesy, no audience building)
```

### Format Balance
```
✅ Good:
- Text: 60%
- Visual: 30%
- Video: 10%

Balance based on:
- Audience preference
- Resource availability
- Channel requirements
```

## Repurposing Workflows

The agent plans systematic repurposing:

```markdown

**Primary Publication:**
- Blog (SEO-optimized)

**Repurpose Into:**

1. Email Newsletter
   - Extract key insights
   - Add personal commentary
   - Include CTA to full post

2. LinkedIn Article
   - Reformat for LinkedIn
   - Add platform-specific hook
   - Native LinkedIn post

3. Twitter Thread
   - Break into 7-10 tweets
   - One main point per tweet
   - Link to full article at end

4. Instagram Carousel
   - 5-7 slides
   - Key points as visuals
   - Swipe-through format

5. YouTube Video (Optional)
   - Script from blog outline
   - Screen recording or talking head
   - Embed in blog post

**Production Time:**
- Blog: 4 hours
- Repurposing: 2 hours
- Total: 6 hours for 5+ content pieces
```

## Best Practices

When using this agent:

1. **Plan Ahead** - Create calendars 2-4 weeks in advance
2. **Batch Production** - More efficient than daily creation
3. **Repurpose Everything** - 1 piece → 5+ formats
4. **Track Performance** - Double down on what works
5. **Stay Flexible** - Adjust based on results and news

## Agent Limitations

This agent plans content, but doesn't:
- Write the actual content (use skills for that)
- Create visuals (focuses on strategy)
- Manage publishing tools (you'll need to execute)
- Do keyword research (run /keyword-research first)

Think of this agent as your content strategist and planner, not your content producer.
