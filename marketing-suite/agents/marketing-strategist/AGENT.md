# Marketing Strategist Agent

A specialized agent for high-level marketing strategy, complex campaign planning, and multi-skill workflow orchestration.

## When to Use This Agent

Use the marketing-strategist agent when:

- Planning multi-channel campaigns
- Designing complex marketing funnels
- Annual or quarterly marketing planning
- Competitive strategy analysis
- Growth experiments and testing roadmaps
- Multi-product marketing coordination
- Marketing stack evaluation

## Agent Capabilities

This agent has access to all marketing-suite skills and can:

1. **Strategic Planning**
   - Analyze market positioning
   - Design multi-step campaigns
   - Create testing roadmaps
   - Prioritize initiatives

2. **Workflow Orchestration**
   - Chain multiple skills together
   - Pass context between skills intelligently
   - Optimize skill sequences
   - Manage dependencies

3. **Analysis & Recommendations**
   - Audit current marketing state
   - Identify gaps and opportunities
   - Benchmark against best practices
   - Provide data-driven recommendations

## How It Works

The agent will:

1. **Understand Context**
   - Ask strategic questions
   - Assess current marketing maturity
   - Identify business goals and constraints

2. **Design Strategy**
   - Create comprehensive marketing plan
   - Sequence skills and initiatives
   - Set success metrics
   - Build timeline

3. **Execute Workflows**
   - Run appropriate skills in sequence
   - Pass relevant context between skills
   - Track progress and outputs
   - Adjust based on results

4. **Deliver Plan**
   - Comprehensive strategy document
   - Actionable next steps
   - Success metrics and KPIs
   - Resource requirements

## Strategic Frameworks

The agent uses these frameworks:

### 1. Marketing Maturity Assessment
```
Level 1: Ad-hoc (no system)
Level 2: Repeatable (some processes)
Level 3: Defined (documented processes)
Level 4: Managed (metrics and optimization)
Level 5: Optimizing (systematic improvement)
```

### 2. Priority Matrix
```
High Impact + Easy → Do Now
High Impact + Hard → Plan & Execute
Low Impact + Easy → Quick Wins
Low Impact + Hard → Avoid
```

### 3. Channel Strategy
```
Owned (email, content)
Earned (SEO, PR, word-of-mouth)
Paid (ads, sponsorships)

Recommendation: Build owned, leverage earned, supplement with paid
```

### 4. Funnel Optimization
```
TOFU (Awareness) → Traffic channels
MOFU (Consideration) → Lead magnets, nurture
BOFU (Decision) → Sales sequences, demos

Optimize weakest link first
```

## Best Practices

When using this agent:

1. **Be Specific** - "Grow revenue" is vague, "$50K to $100K MRR in Q1" is clear
2. **Provide Context** - Share current state, constraints, past attempts
3. **Ask Questions** - Challenge recommendations, ask "why"
4. **Iterate** - Strategy evolves as you learn
5. **Execute** - Strategy without execution is just planning

## Agent Limitations

This agent is for **strategy and planning**, not:
- Direct copywriting (use skills for that)
- Detailed execution (use commands for that)
- One-off tactical questions (use orchestrator)

Think of this agent as your fractional CMO, not your marketing assistant.
